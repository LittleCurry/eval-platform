# Webhook 与开放 API

## 开放 API

- 地址前缀：`https://api.zhijian-crm.com/api/v2`；沙箱环境：`https://api-sandbox.zhijian-crm.com/api/v2`（数据独立，供联调）。
- 鉴权：HTTP Header `Authorization: Bearer <租户级 Token>`，Token 在「开发者设置」生成，可随时吊销。
- **频率限制：默认 100 次/分钟/IP**，超限返回 `429` 并带 `Retry-After` 头；旗舰版可申请提升至 500 次/分钟。
- 幂等：写接口支持请求头 `X-ZJ-Idempotency`（UUID），同键重复提交只生效一次，键保留 24 小时。

## Webhook 事件

- 支持事件：客户创建/更新、线索状态变更、商机阶段变更（赢单/输单）、审批完成、跟进记录新增。
- 投递：HTTPS POST，JSON 载荷，超时 10 秒。

## 签名与重试

| 项 | 规则 |
|----|------|
| 签名算法 | `HMAC-SHA256(secret, rawBody)`，Base64 编码放 `X-ZJ-Signature` |
| 时间戳 | `X-ZJ-Timestamp`（Unix 秒），与服务器时间差 > 300 秒拒绝 |
| 重试 | 失败指数退避重试 **3 次**（5s / 30s / 5min） |
| 幂等 | 事件载荷含 `event_id`，接收方应据此去重 |

## 版本与兼容

- 旧版 `/api/v1` 批量接口已于 2025-06 起进入弃用期，**2025-09-30 下线**（见 E04）。
- 所有 v2 响应包一层 `{ "code": 0, "data": ..., "request_id": "..." }`，非 0 为业务错误。
