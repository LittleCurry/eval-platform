## 文件约定

- 每篇 `.md` 顶部为 YAML frontmatter：`doc_id / title / module / tags / version`。
- 正文用 `#`/`##` 小标题组织 —— 未来切分与 gold 锚点以 (doc_id, 标题/段落) 为稳定参照。
- 文档间事实保持一致（同一数字/规则全库唯一口径），便于出"跨文档检索"的题。

## 出题提示（M1 做评测集时参考）

- 优先从 B/C/D 板块出题（规则、数字、例外最密）。
- 可出跨文档题，例如：查重规则(B01) 与 FAQ(E03) 的呼应、套餐配额(E01) 与字段上限(C03) 的呼应。
