# 数据字典：状态、阶段与枚举

本文是各对象字段的枚举取值与流转规则总表，功能文档（B/C 板块）引用同一套口径。

## 线索状态

| 取值 | 含义 | 备注 |
|------|------|------|
| 新建 | 刚创建，尚未分配 | 初始状态 |
| 已分配 | 已归属某负责人 | 自动或手动分配 |
| 跟进中 | 负责人已登记至少一条跟进 | 由"已分配"在首次跟进后自动切换 |
| 已转化 | 已转化为客户 | 转化后原线索锁定不可编辑 |
| 已失效 | 确认无效 | 必须填写失效原因 |

**失效原因**枚举：重复 / 无效 / 无意向 / 无法联系 / 其他。

## 商机阶段

流转顺序：初步接触 → 需求确认 → 方案报价 → 商务谈判 → 赢单 / 输单。

- **赢单**：需填写实际金额与赢单日期。
- **输单**：必须选择输单原因。
- 阶段可回退（如从"方案报价"回到"需求确认"），回退需有编辑权限。

**输单原因**枚举：预算不足 / 竞品胜出 / 内部决策变化 / 价格分歧 / 其他。

## 跟进方式

电话 / 邮件 / 上门拜访 / 线上会议 / 微信 / 其他。

## 来源渠道（线索）

官网留资 / 展会 / 转介绍 / 主动外呼 / 广告投放 / 其他。

## 金额与币种

- 默认币种 CNY（人民币），暂不支持多币种并行。
- 金额精度为 2 位小数；报表统计按 2 位小数四舍五入后汇总。

## 删除与恢复

所有对象的删除记录进入回收站统一保留 **30 天**，管理员可恢复；到期物理删除（见 C05）。
