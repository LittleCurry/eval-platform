# 产品简介与核心概念

知简 CRM（ZJ-CRM）是杭州知简科技有限公司推出的云原生客户关系管理系统，当前版本 4.2.0，面向 B2B 销售团队，覆盖线索、客户、商机与跟进的完整销售闭环。

## 核心对象

| 对象 | 说明 |
|------|------|
| 客户（Account） | 企业级档案，是数据挂靠的主体 |
| 联系人（Contact） | 客户下的具体人员，一个客户可挂多个联系人 |
| 线索（Lead） | 未经确认的潜在客户记录，来源可为官网留资、展会、外呼等 |
| 商机（Opportunity） | 可成交的销售机会，必须挂靠客户 |
| 跟进记录（Activity） | 对客户/商机的每次互动，按时间轴记录 |
| 自定义对象 | 按业务扩展的数据对象（如合同、项目），受套餐配额限制 |

## 对象关系与流转规则

1. 一个客户可拥有多个联系人、多个商机与多条跟进记录。
2. 线索转化时，系统自动创建或匹配已有客户，并把商机挂到该客户下；转化后线索状态置为"已转化"。
3. 被删除的记录进入回收站，保留 30 天，到期物理删除不可恢复（见 C05）。

## 常用术语

- **租户**：一家使用知简 CRM 的独立企业空间，数据相互隔离。
- **席位**：一个可登录账号的许可单位，按套餐购买（见 E01）。
- **负责人**：记录当前的归属成员；线索与商机均有负责人概念。
- **共享规则 / 字段权限**：见 C02。
