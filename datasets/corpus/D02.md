# 邮件与企微集成

## 邮件集成

- 绑定：成员可在个人设置中绑定一个常用邮箱（需验证所有权）。
- 来信自动建档：发往绑定邮箱且主题含客户名称的邮件，可自动关联客户并在其时间轴生成跟进记录（跟进方式=邮件，见 A04）。
- 未知发件人默认生成新线索并进入未分配池，防止漏单。
- 解析置信度低于阈值的邮件进入"待认领"列表，人工处理后不再重复建档。

## 企业微信集成

| 能力 | 说明 |
|------|------|
| 授权登录 | 成员可用企微扫码登录（需管理员在企业微信后台完成授权） |
| 消息通知 | 跟进提醒、审批待办、自动回收通知推送到企微应用消息（见 B02/B04/C04） |
| 线索来源 | 企微客户群聊中 @机器人 登记线索，默认来源渠道=其他，可在机器人设置中修改 |

- **防骚扰限制**：通过平台向客户批量发送的企微消息默认上限 **50 条/成员/天**，超限当日拦截并提示次日再发。
- 解绑：成员解绑后其名下推送停止，历史消息记录保留。

> 关联：审批与自动化通知通道见 C04；消息限额相关审计见 C05。
