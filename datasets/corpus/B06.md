# 批量导入与导出

## 支持的格式与限制

| 项目 | 限制 |
|------|------|
| 文件格式 | `.xlsx`、`.csv`（UTF-8 编码） |
| 单次导入行数 | ≤ **5 万行** |
| 文件大小 | ≤ **20MB** |
| 导入记录留存 | 30 天（含错误文件下载链接） |

## 导入流程

1. 下载官方模板（表头为系统字段名，勿修改）。
2. 映射校验：列名与字段映射成功后预览前 20 行。
3. 必填项缺失、枚举值非法、日期格式错误 → 该行标记失败，不中断整体导入。
4. 完成后生成导入报告：成功 N 行 / 失败 M 行；失败文件按**原行号**标注错误原因，可下载修正后重导。

## 查重与更新策略（导入场景）

- 客户：按统一社会信用代码/客户名称查重（见 B01）；默认"跳过重复"。
- 联系人/线索：按手机号查重；默认"跳过重复"。
- 可选策略："更新已有"（按查重键匹配后覆盖指定字段），需管理员权限，操作前强制导出备份。

## 不可导入字段

系统字段（id、创建时间、创建人）不可导入；"负责人"可按邮箱/姓名解析，解析失败该行报错。

## 导出

- 列表/报表导出均受查看权限约束（C02）。
- 单次导出上限：报表 10 万行（见 B05）；数据列表 5 万行，超出请筛选分批。

> 关联：从其他系统迁入走迁移向导见 D03。
