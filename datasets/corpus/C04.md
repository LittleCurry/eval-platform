# 审批流与自动化

## 审批流

- 适用对象：商机、客户、自定义对象。
- 组成：触发条件（对象 + 条件表达式）→ 审批节点（按角色/成员/直属上级）→ 动作（通过/拒绝/退回）。
- 典型示例：**商机折扣超过 20%** → 提交直属上级审批 → 通过后阶段才可推进到"方案报价"。
- 审批中记录加锁，不可编辑关键字段；审批记录留痕可查。

## 工作流自动化

触发器与动作组合，支持多条优先级：

| 触发器 | 示例 |
|--------|------|
| 记录新建 | 新线索自动打标"新线索-待跟进" |
| 字段变更 | 商机阶段变为"赢单" → 通知经理 |
| 定时 | 每日 9:00 汇总昨日新增商机推送销售群 |

| 动作 | 说明 |
|------|------|
| 发送通知 | 站内/企微/邮件 |
| 修改字段 | 需满足权限约束，越权字段跳过并记录 |
| 创建任务 | 生成跟进待办（回访计划见 B04） |
| 调用 Webhook | 触发外部系统（见 D01） |

## 与分配的关系

- 线索自动分配/回收属于"系统内置自动化"，在工作流页面只读展示，不占用自定义工作流条数（见 B02）。
- 工作流执行日志保留 **90 天**，可用于排查触发异常。

## 配额

审批流与工作流数量按套餐：基础版 不开放；专业版 审批流 10 条 / 工作流 20 条；旗舰版 审批流 50 条 / 工作流 100 条。

> 关联：审批涉及字段权限见 C02；Webhook 调用见 D01。
