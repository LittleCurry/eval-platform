# 字段与页面布局定制

## 自定义字段

| 类型 | 说明 |
|------|------|
| 文本 / 长文本 | 长度上限 255 / 10000 字符 |
| 数字 / 金额 | 金额精度 2 位小数 |
| 日期 / 日期时间 | — |
| 单选 / 多选 | 选项值全局唯一，删除选项需先清理引用数据 |
| 引用（Lookup） | 指向客户/联系人/商机/自定义对象 |
| 公式 | 只读，基于数值/日期字段计算 |

**配额上限（每对象可建自定义字段数）**：基础版 20 个，专业版 60 个，旗舰版 120 个（套餐差异见 E01）。

## 字段约束规则

1. **类型不可变更**：字段创建后其类型不可修改，只能新建字段并迁移数据（避免历史数据损坏）。
2. 必填与唯一校验：可设置"创建即必填"与"唯一值"；唯一冲突时保存报错并定位首条冲突记录。
3. 删除：字段删除为"归档"，历史数据保留但不再展示/参与筛选，归档字段可恢复，物理清理需联系技术支持。

## 页面布局

- 布局由"字段区块"组成，可对不同角色显示不同布局（如销售视图隐藏内部成本字段）。
- 支持列表视图、看板视图（按阶段/负责人/自定义单选分组）与筛选器保存共享。

## 统计联动

- 自定义字段不参与内置报表统计（见 B05），如需参与请用自定义报表的"维度/指标"添加。

> 关联：自定义字段的可见性受字段级权限控制（C02）。
