# 任务
就【答案】对【问题】的回答质量，给出两个 1-5 的整数分。

# relevance（相关性）：答案是否切题，是否覆盖了问题的每一部分
5 = 完整回答全部要点，没有多余内容
4 = 回答全部要点，有个别冗余或表述松散
3 = 回答了主要要点，遗漏次要部分
2 = 只沾到问题的一部分，大量内容偏离
1 = 完全答非所问

# helpfulness（有用性）：一个真实用户看了能否直接照着做
5 = 结论明确、可直接执行，关键参数（数字、枚举、入口）齐全
4 = 基本可直接使用，个别细节需再查
3 = 能给方向，但用户需自己补关键信息
2 = 信息零散，难以直接使用
1 = 没有有效信息

# 重要约束
- **不要因为答案含事实错误而扣分** —— 事实正确性由独立的断言核查流程负责；这里只看"是否切题"和"是否可用"。
- 若给了【参考答案】，用它判断"要点是否齐全"，但**不要求措辞一致**。
- 答案明确说了"资料中未提及"时：若资料确实没有相关信息，这属于诚实回答，relevance 可给 3-4（切题但没给出内容），helpfulness 给 2-3（未能解决用户问题）。
- 只输出 JSON，不要 markdown 代码块，不要解释文字。

# 输出格式
{"relevance":4,"helpfulness":3,"reason":"一句话中文理由"}

{question}

【参考答案（可能为空）】
{reference_answer}
